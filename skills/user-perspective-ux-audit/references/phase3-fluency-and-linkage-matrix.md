# 阶段三审查细则：交互流畅度与禁用 `F5` 的多界面联动性矩阵 (Stage 3 Matrix)

只有在**阶段一（第一印象门禁）**与**阶段二（无提示全功能发现与工作流完通门禁）**均通过后，才启用本文档进行深度跨界面联动与交互压测。本阶段聚焦**“操作心流是否顺滑”**以及**“各页面状态是否实时互通”**。

---

## 第一部分：交互流畅度与反馈闭环 (Interaction Fluency)

流畅度不仅指帧率快慢，更指**“用户的每一次操作是否都有符合预期的即时回应，且心流不被打断”**。

### 1.1 即时反馈与防抖防重
- **可点击感知（Affordance）**：鼠标移入按钮、卡片、表格行操作项时，是否有清晰的指针变化（`cursor: pointer`）与悬停态（Hover）？禁用态（Disabled）是否不仅变灰，还能让用户明白**为什么当前不能点**（如悬停提示“请先填写标题”）？
- **异步等待反馈**：点击提交、保存、搜索、导出、AI 生成等耗时操作（`> 200ms`）时：
  - 按钮是否立即进入 `Loading` 态并锁定防连点？（**必测动作**：故意对新建/提交按钮快速连续双击，检查是否插入了两条重复数据或弹出两条重复提示！）
  - 数据加载时是否有平滑的骨架屏（Skeleton）或局部加载指示，还是整页突然变白、或者卡住几秒毫无动静让用户以为没点上？
- **操作结果确认**：保存、删除、复制成功后，是否有明确且不打扰的反馈（如轻量 Toast 提示、按钮短暂变为“已复制 ✓”、列表高亮新增项）？

### 1.2 过渡丝滑度与视觉稳定性
- **零布局跳动（Zero Layout Shift）**：切换标签页、异步图片/列表加载完成、展开折叠面板或显示表单报错提示时，周围的按钮和内容是否突然上下剧烈跳动导致用户误点？
- **弹窗与抽屉体验**：打开/关闭弹窗（Modal）、侧滑抽屉（Drawer）、下拉菜单时过渡是否自然？弹窗打开后键盘焦点是否自动落入首个输入框？按 `Esc` 键能否正常关闭？

### 1.3 表单容错与防丢稿保护
- **友善的校验时机与文案**：
  - 必填项是否有提前标识，而不是等用户填完十几个空点提交才报错？
  - 故意提交空表单、超长字符、非法格式（如错误邮箱/负数）时，报错是否精准定位到具体字段下方且用人话指导修改？
  - **底线红线**：表单提交失败或校验不通过时，**绝对不能清空用户已经辛苦填好的其他字段内容！**
- **防误触与防丢稿**：
  - 在弹窗或编辑页填写了一半内容时，如果不小心点到弹窗外部灰色遮罩或点击返回，系统是直接静默销毁所有输入，还是给予保留/二次确认提示？
  - 删除、清空、重置等破坏性操作，是否有清晰的二次确认（最好点名确认对象，如*“确定删除项目「年度预算」吗？删除后无法恢复”*）或提供“撤销（Undo）”机制？

### 1.4 拒绝“死胡同界面”（Dead-End Prevention）
- 任何详情页、设置子页、分步向导页、报错页或搜索无结果页，是否都有显眼的**返回上一级 / 取消 / 清空筛选条件**入口？（不能逼迫用户只能靠点浏览器刷新或重输网址自救）。

## 第二部分：多界面联动性测试矩阵 (Cross-View Linkage Matrix)

许多软件单看每个页面似乎都能用，但连起来用时却像“散装拼图”——A 页面改了数据，B 页面还是旧的；点进去再退回来，刚才筛好的列表全丢了。

**强制要求**：测试员需结合阶段二已经探明的全量页面/面板/弹窗，针对当前软件适用的业务场景，**至少完整实测 5 条下表中的跨界面联动链路**，且全程**禁止使用浏览器 `F5` 硬刷新来掩盖状态不同步缺陷**！

### 联动链路 1：增删改状态变更 → 全局概览与角标联动
- **操作路径**：在列表页、详情页或弹窗中执行【新建一条记录 / 修改关键状态（如待办→已完成、金额变更）/ 删除一条记录】。
- **跨界面核查点**（通过软件自身导航切换过去观察）：
  1. **首页 / 仪表盘（Dashboard）**：统计数字卡片、进度条、图表曲线、“最近动态”列表是否立即同步更新？
  2. **侧边栏 / 顶部栏角标（Badges）**：导航栏上的待处理数量气泡、容量进度条是否实时增减？
  3. **全局搜索**：立刻在顶部全局搜索框搜索刚新建/改名的条目，能否搜到最新名称？搜索刚删除的条目，是否已不再出现（或点击不会导致白屏崩溃）？

### 联动链路 2：主从视图与关联选择器联动（Master-Detail & Selector Sync）
- **操作路径**：
  - 场景 A：在【分类管理 / 标签管理 / 成员管理 / 基础设置】中新增、重命名或禁用某个分类/标签 `X`。
  - 场景 B：进入某条数据的【详情页】修改其标题、负责人、优先级或标签。
- **跨界面核查点**：
  1. 打开【新建业务单据弹窗 / 筛选器下拉框】，里面引用的分类/标签下拉列表是否立刻包含刚新建或改名后的 `X`？（常见 Bug：下拉框缓存了旧列表，必须重进网站才刷新）。
  2. 从详情页返回【主列表页 / 看板视图 / 日历视图】，对应卡片上的标题、状态标签、排序位置是否已同步为最新值？

### 联动链路 3：导航流转与列表上下文保持（Navigation & Context Persistence）
- **操作路径**：在列表页【输入搜索词 / 勾选筛选条件 / 翻到第 2 页 / 向下滚动一段距离】→ 点击某一条进入【详情页或编辑页】→ 点击界面上的【返回按钮】（Web 端额外再测一次【浏览器后退/前进按钮】）。
- **跨界面核查点**：
  1. 返回列表页后，刚才的**搜索词、筛选条件、排序方式、页码**是否依然保留？（如果每次看完详情退回来筛选条件全部清零，批量处理体验极差）。
  2. **导航高亮同步**：无论通过侧边栏点击、面包屑跳转、首页快捷入口跳转还是浏览器后退，左侧/顶部菜单栏的**当前激活态高亮（Active Tab）**、顶部面包屑路径、窗口标题是否始终与当前实际展示的界面严丝合缝？

### 联动链路 4：全局设置与环境状态跨组件广播（Global Settings Propagation）
- **操作路径**：切换【深色/浅色主题】、【界面语言】、【个人头像/昵称】、【货币/时间格式】或某个【全局功能开关】。
- **跨界面核查点**：
  1. 依次切过主页面、二级设置页、打开模态弹窗（Modal）、下拉浮层（Popover/Tooltip）、图表画布（Canvas/SVG）、空状态插画。
  2. 检查是否所有界面元素全部实时响应切换？重点抓：右上角头像昵称改了但评论区/侧边栏左下角还是旧名字；主页面切了深色模式但弹窗或图表文字还是黑字黑底；切换语言后部分菜单标题没跟着变。

### 联动链路 5：数据生命周期边界全流转（0 → 1 → N → 0 Lifecycle）
- **操作路径**：模拟真实用户从零开始到清理数据的完整生命周期：
  1. `0 条数据（空状态）` → 点击空状态引导按钮新建第 `1` 条数据；
  2. 继续新建多条数据，其中刻意包含一条**超长标题（50+ 字符）**和一条**带特殊符号（引号/`&`/Emoji）**的数据；
  3. 将数据逐一删除，直到删掉最后 `1` 条回到 `0` 条。
- **跨界面核查点**：
  - `0 → 1` 时：新手引导横幅/空状态占位图是否干净消失并顺滑切换为正常数据视图？
  - 超长文本/特殊字符数据：在列表卡片、侧边栏最近访问、面包屑、删除确认弹窗、关联下拉框等**所有引用该名称的界面**中，有没有撑爆布局、挤走右侧操作按钮或出现 HTML 转义乱码（如 `&amp;`）？
  - `1 → 0` 时：删空最后一条后，分页器是否正常隐藏或归零（严查出现“第 2 页 / 共 0 条”导致列表空白但其实第 1 页还有数据，或删空后只剩表头不显示空状态引导）？

### 联动链路 6：窗口缩放与多面板协同联动（Layout & Split-Pane Linkage）
- **操作路径**：打开左侧导航折叠开关、右侧详情分栏抽屉或模态框的同时，动态调整浏览器视口宽度（桌面宽屏 ↔ 平板/窄屏）或最大化/还原桌面客户端窗口。
- **跨界面核查点**：
  - 侧边栏折叠/展开时，主内容区图表（ECharts/Canvas 等）是否自动重算宽度而非被截断或留白？
  - 已打开的浮层菜单、抽屉面板在窗口变窄时是否自适应位置，是否出现按钮被挤出屏幕可视区无法点击关闭的情况？
